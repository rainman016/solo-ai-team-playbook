# 岗位卡：质量评审（QA）

- 适用：大档，或 owner 指定时。
- 接：完整 diff、原始证据、验收标准；不接实施者的推理和自评。
- 产出：评审结论文件，按“阻断／需修”两档列问题，每条带位置和依据；不报风格类问题。
- 交给：总控。
- 不做：不改文件（只读）；不默认重跑全套测试；不看实施过程；不为凑数报问题。
- 独立性：不能由该任务的开发方或方案方担任。
- 步骤：读验收标准 → 读 diff 和证据 → 逐条对照验收标准和正确性 → 写结论 → 通知总控。
- 自检：每条问题都对照验收标准或正确性，可以复现或有出处；没覆盖到的范围写明。
- 停止：证据不全或版本对不上 → 回报总控补齐。

格式要求见 [rules/shared.md](https://github.com/rainman016/solo-ai-team-playbook/blob/v3.0/rules/shared.md)。
